# Ejercicio-11---Modelo-Entidad-Relaci-n-de-un-Sistema-de-Venta-de-Entradas-para-Conciertos
Este ejercicio consiste en diseñar un modelo Entidad-Relación (DER) para un sistema de venta de entradas y gestión de eventos musicales[cite: 7]. El modelo permite administrar recintos, sectores, conciertos, tickets, clientes y transacciones de compra[cite: 7].
